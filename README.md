# Gambit Chess

브라우저에서 도는 체스. AI와 1:1로 둔다.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # AI 엔진 테스트
npm run build
```

## 구성

| 파일 | 역할 |
| --- | --- |
| `src/main.ts` | 보드 렌더링, 클릭 입력, 상태 표시 |
| `src/ai.ts` | 알파-베타 미니맥스 + 기물 가치/위치 평가 |
| `index.html` | 마크업 + 전체 CSS |

규칙 판정(캐슬링, 앙파상, 승진, 체크메이트, 무승부)은 `chess.js`가 담당한다.
직접 짜면 엣지 케이스에서 틀린다.

## 난이도

`쉬움`~`매우 어려움`은 탐색 깊이 1~4수. 깊이 4는 한 수에 몇 초 걸린다.

## 의도적으로 생략한 것

- **언더프로모션** — 승진은 항상 퀸 (`src/main.ts`). 필요해지면 선택 UI 추가.
- **드래그 앤 드롭** — 클릭 두 번으로 충분.
- **Web Worker** — 깊이 4까지는 메인 스레드로 버틴다. 더 깊게 가려면 옮길 것.
- **오프닝 북 / 기물 잡기 연장 탐색** — AI가 약하다고 느껴질 때.
